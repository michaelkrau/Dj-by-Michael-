# Dj-by-Michael-
מדריך מקצוע ביצירת סטים מוזיקליים לאימוני פיטנס

A professional guide in Hebrew on how to construct a music set for workout using the app Cubasis 3 on your iPad/iPhone/Mac.

## 📚 המדריך המלא / Full Guide

**[מדריך ליצירת סט פיטנס - לחץ כאן](./מדריך-ליצירת-סט-פיטנס.md)**

## תוכן / Contents

המדריך כולל הוראות שלב-אחר-שלב ליצירת סט מוזיקלי רציף של 50 דקות:
- הכרת אפליקציית Cubasis 3
- ייבוא וסידור 10-15 שירים
- יצירת מעברים חלקים (Crossfades)
- התאמת רמות עוצמה
- ייצוא הסט הסופי
- טיפים מקצועיים ופתרון בעיות

The guide includes step-by-step instructions for creating a 50-minute continuous fitness music set:
- Introduction to Cubasis 3 app
- Importing and arranging 10-15 songs
- Creating smooth transitions (Crossfades)
- Adjusting volume levels
- Exporting the final set
- Professional tips and troubleshooting

## דרישות / Requirements

- iPad, iPhone או Mac / iPad, iPhone or Mac
- אפליקציית Cubasis 3 / Cubasis 3 app
- 10-15 שירים שנרכשו באופן חוקי / 10-15 legally purchased songs
