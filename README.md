# DJ by Michael - Professional Production Guides

Professional guides for constructing high-energy workout sets using Cubasis 3 on iPad.

## 📚 Available Guides

### [Production Workflow: 50-Minute Fitness Mix](PRODUCTION_WORKFLOW.md)
**Comprehensive technical guide for creating a fitness mix in Cubasis 3**

Master the art of blending vintage Disco (70s-90s) tracks with modern Techno beats at 128-130 BPM.

#### What You'll Learn:
- ⚙️ **Project Setup**: Optimal audio settings and BPM locking
- 🎵 **Advanced Time-Stretching**: Using zplane élastique algorithm to warp and quantize tracks with live drummers
- 🎚️ **Automation & Transitions**: Drawing volume curves and filter sweeps for seamless DJ-style mixing
- 🎤 **Layering & Mashups**: Vocal isolation techniques and creative layering over modern beats
- 🔊 **Gym Mastering Chain**: Professional plugin chain for loud, punchy mixes optimized for noisy environments

**Target Audience**: Audio engineers, DJs, and fitness instructors creating pre-recorded workout mixes.
